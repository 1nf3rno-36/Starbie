# Starbie
A desktop pet, called Starbie. It uses a XIAO-ESP32-C3 microcontroller to control a DHT11 Temperature and Humidity sensor, a 10K Ohms resistor, MPU6050 module, 0.96 inch Oled display, and 2 MX switches. The sensors are used to sense movement and then carry out actions by the pet on the Oled e.g. shaking left means "PET" which sends hearts up in the air. PCB designed in KiCAD and code written in Arduino IDE.
